# Support (`SUPPORT.md`)

## Where to Get Help

1. **Documentation first:** Check [`README.md`](README.md), [`docs/faq.md`](docs/faq.md), [`docs/configuration.md`](docs/configuration.md), and [`docs/glossary.md`](docs/glossary.md).
2. **Replication & verification issues:** Follow [`REPLICATION.md`](REPLICATION.md) and confirm `npm test && npm run lint` passes on Node >= 22 and Python >= 3.12.
3. **Questions & discussions:** Open a GitHub Discussion or use the **Question** issue form at `https://github.com/0thernes/omega-triscale-observatory/issues`.
4. **Bugs or audit findings:** Open an issue using the **Bug or finding** form and select exactly one of the 10 Build Standard finding classes.
5. **Security issues:** Follow [`SECURITY.md`](SECURITY.md) — never report security vulnerabilities publicly.
6. **Direct contact:** Alexander Stephen Donahue (`0_0@0thernes.art`).
